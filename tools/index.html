Tools

One-liners to bootstrap a GPU box, drop a research docs site into any repo, or install shared Claude guidelines.

VM setup
/setup.sh

Idempotent bootstrap for a fresh SSH / RunPod machine.

  • bashrc aliases (ll, gs/wgs, tls/ta, dus) + git prompt
  • GitHub CLI (gh)
  • Claude Code CLI
  • Hugging Face CLI (hf)
  • gpustat
Install
curl -fsSL https://nityanandmathur.com/setup.sh | bash
Then auth
source ~/.bashrc
gh auth login
claude
hf auth login
Research docs kit
/docs.sh · preview

Drops the house docs/ scaffold into the current repo (theme, hub + report pages, serve.py).

  • Re-run refreshes theme files only; keeps authored pages
  • --force overwrites pages
  • Live design preview at /docs/
Install
curl -fsSL https://nityanandmathur.com/docs.sh | bash
With title
curl -fsSL https://nityanandmathur.com/docs.sh | bash -s -- \
  --title "My Paper" --tagline "One line."
Preview locally
python3 docs/serve.py
CLAUDE.md
/claude.md

Shared behavioral guidelines for Claude Code. Writes CLAUDE.md at the repo root.

Install
curl -fsSL https://nityanandmathur.com/claude.md -o CLAUDE.md

Safe to re-run. Source lives in nityanandmathur.github.io.
